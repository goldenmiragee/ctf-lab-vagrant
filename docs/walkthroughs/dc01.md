# Walkthrough — `dc01` (192.168.56.40) · Active Directory

Windows Server 2019 domain controller for **ctflab.local** (NetBIOS **CTFLAB**). **Derived**
flags — Active Directory attack paths. Provisioned by `provision/dc01.ps1`.

> ⚠️ **Status: blocked in this build.** The 10 GB box downloads and boots, but WinRM
> `init_auth` times out on VirtualBox 7.2 (reproduced 3×), so automated provisioning does not
> complete. See [known-issues](../known-issues.md) for the confirmed observation and
> mitigations (raised WinRM timeouts, a newer Windows box, or manual provisioning over RDP).

## Intended lab (once provisioned)

`provision/dc01.ps1` seeds intentionally-weak AD:

- **`jstiles`** — Kerberos pre-auth disabled → **AS-REP roasting**.
- **`svc_sql`** — SPN set + weak password → **Kerberoasting**.
- **`svc_web`** — **unconstrained delegation**.
- **`lowpriv`** — **`GenericWrite` over Domain Admins** (dangerous ACL).

## Intended attack path

1. **Recon** the domain — short name is `CTFLAB`.
2. **AS-REP roast** `jstiles`, crack offline (`hashcat -m 18200`).
3. **Kerberoast** `svc_sql` (request the TGS, `hashcat -m 13100`).
4. Abuse the **dangerous ACL** (`lowpriv` → add self to Domain Admins) or **unconstrained
   delegation** to capture a TGT.
5. With DA: **DCSync** (`secretsdump`) → **golden ticket** (KRBTGT) → domain-wide persistence;
   move laterally with **pass-the-hash**.

## Tools

`impacket` (GetNPUsers, GetUserSPNs, secretsdump, ticketer), `Rubeus`, `BloodHound`,
`CrackMapExec`, `hashcat`.
