# Screenshots

- **`scoreboard.svg`** — a UI preview of the scoreboard that mirrors the real styling
  (`scoreboard/style.css`). It renders directly on the GitHub README so the front page looks
  complete out of the box.

To use a real capture instead: run the scoreboard (`python scoreboard/server.py`), take a
screenshot, save it as `scoreboard.png` here, and update the image link at the top of the
root `README.md` from `scoreboard.svg` to `scoreboard.png`.
